# CW QSO Auto v1.0 stable snapshot

This is a backup of the exact selected-message repeat application confirmed
working on UV-K5 V3 by its author. It is not a V7 port. The original contribution
commits and PR branch remain unchanged.

- Branch: `stable/cw-qso-auto-v1.0`
- Annotated tag: `cw-qso-auto-v1.0-stable`
- Installable app: [`archive/apps/v6.3.0/CWQSOAuto-v1.0-stable.app`](../../../archive/apps/v6.3.0/CWQSOAuto-v1.0-stable.app)
- Standalone offline editor: [`editor.html`](editor.html), embedding that exact app.
- Overlay: 4084/4096 bytes including 92 bytes BSS; assets: 2286 bytes.
- APP SHA256: `40d20652b008e8134b26faf5e69116b8335ffb3a7c944819d4c15abdbc5d037b`.
- Application header version remains `0.4`; v1.0 is the stable snapshot/tag name.

All 16 slots have names (0–12 printable ASCII characters) and up to 64 CW
payload bytes. SIDE 1 repeats the captured selection; SIDE 2 stops after the
current message. REPEAT is persistent, 1–15 seconds, default 5. SETTINGS PTT
uses straight keying. Only `{RST}` is dynamic; callsign/name remain literal text.
Early speaker activation is retained. See FORMAT-NAMES.md and REPEAT-SELECTED.md.

## Rebuild

Use GNU Arm Embedded GCC 13.3.Rel1 (13.3.1). From the repository root:

```
# Set ARM_CC to arm-none-eabi-gcc (or its full executable path).
python App/apps/cwqsoauto/build.py
```

The strict linker enforces the original 4096-byte overlay limit. Asset binary
and header are generated by gen_assets.py from the checked-in C defaults,
identity header and asset builder. The repo includes app_assets.py, pack_app.py,
API headers and linker script needed by this build. Generated ELF/MAP/BIN,
caches, host executables and logs are deliberately excluded from Git.

The output `App/apps/cwqsoauto/CWQSOAuto.app` must match the archived stable
application byte for byte. No firmware or other application source was changed.
Source C, asset generator, identity header, linker script and HTML are stored
without text conversion; the HTML's exact bytes are preserved too.

## Use and verify

Open editor.html locally, personalize, export, and install the resulting APP
with the usual application loader on compatible ABI 1/API 3 F4HWN firmware.
Keep exported files for backup. Importing the old approved profiles preserves
their executable; it does not silently upgrade them.

For the current software tests (host GCC, Node and optional Edge required):

```
python App/apps/cwqsoauto/test/experimental.py --browser
```

The older run.py/release.json and historical release docs describe the earlier
PR binary and retain its pins/expectations. Use experimental.py for this snapshot.
The older archived CWQSOAuto.app is intentionally retained as a legacy test
fixture; the stable binary is the explicitly versioned file linked above.

The user confirmed the stable APP on hardware. Software regression results
for the same code were recorded before this backup; no new hardware results
are claimed. STABLE-v1.0.json lists reproducibility inputs and SHA256 hashes of
their committed Git contents.
