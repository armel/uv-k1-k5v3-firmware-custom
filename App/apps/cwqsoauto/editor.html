CW QSO Auto · Bank16

Vos messages, à votre rythme.

Le binaire de référence est inclus : personnalisez les 16 messages, puis téléchargez votre application pour UV Studio. Ce fichier HTML fonctionne hors ligne, sans serveur. Remplacez F4XXX par votre indicatif et SEB par votre prénom avant un QSO réel.

La référence QNM1 permet de nommer les 16 messages. Les anciens profils approuvés restent importables pour modifier leurs contenus, mais ne stockent pas de noms. Leur code et leurs commandes sont conservés, sans migration automatique.

Vérification de la référence embarquée…

Alphabet accepté : A–Z, 0–9, espace, / et ?. Aucune conversion automatique.

{RST} insère le report courant et compte pour 1 octet. Pas d’espace au début, à la fin ou en double. Un message vide désactive son émission.

Noms : 0 à 12 caractères ASCII visibles, identiques pour les 16 emplacements. Le numéro est fixe. Un nom vide laisse le numéro seul à l’écran. Le nom n’est jamais transmis. Les accents ne sont pas pris en charge par la police du poste.

Version fournie : UP/DOWN parcourt les 16 messages, PTT transmet la sélection. SIDE 1 répète le message sélectionné ; SIDE 2 laisse finir le message commencé puis arrête. Dans SETTINGS, UP/DOWN règle REPEAT de 1 à 15 s (5 s par défaut, sauvegardé) et PTT sert de pioche. MSG 15 et 16 restent accessibles par navigation. Aucun remplacement d’indicatif ou de prénom n’est automatique : modifiez les textes concernés. Seul {RST} est un jeton.

Personnalisation et installation / Customization and installation

Modifiez notamment MSG 01 et 02 pour remplacer F4XXX et SEB. Cliquez sur « Vérifier et télécharger », conservez la copie .app puis importez-la dans la vue Applications / Apps d’UV Studio pour l’installer sur un firmware F4HWN compatible ABI 1 / API 3 (série 6.3.0).

UV Studio : armel.github.io/uvstudio. L’édition et la génération restent hors ligne ; l’installation avec UV Studio est une étape séparée.

Conservez le .app téléchargé : le réimporter permet de reprendre les 16 textes. Rien n’est enregistré automatiquement après fermeture de cette page. Recharger les valeurs par défaut remplace les champs affichés, sans modifier vos fichiers.

The reference app is embedded. Replace F4XXX and SEB in messages 01/02, edit the texts, download the validated .app, then install it through UV Studio’s Applications view. Keep and reimport your .app to restore your messages. Old compatible imports retain their original executable and controls.
