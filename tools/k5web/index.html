多普勒固件手台工具

适用于 UV-K1 / UV-K5 V3 / UV-K6 V3（PY32F071）F4HWN 固件。选择左侧功能菜单开始使用。

固件刷写

固件刷写（Bootloader 协议，256 字节/页）

刷写主固件（裸 .bin，写入 0x08002800）。步骤：① 按住 PTT 键不放，同时开机，进入刷机模式（屏幕不亮，对讲机持续广播设备信息）→ ② 本页选择固件文件 → ③ 点"开始刷写"。

刷写中请勿断电或拔线；完成后断开串口并重新开机。刷机失败不会变砖——保持按住 PTT 重新开机即可再次进入刷机模式重刷。

导出校准数据

导出校准数据（512 字节）

读出机内校准区（EEPROM 0xB000~0xB200：电池电压校准、RSSI 校准等），保存为 calibration.dat 文件。刷写新固件前建议先导出备份。对讲机保持正常开机即可，无需进刷机模式。

导入校准数据

导入校准数据（512 字节）

把之前导出的 calibration.dat 写回机内校准区。警告：写错校准数据会导致频率/功率/电量显示异常，请确认文件来自同一台机器。导入完成后对讲机自动重启生效。

中文字库

中文字库刷入（GB2312 16×16）

字库写入外置 FLASH 0xA0000，与白头佬多系统共享字库位置兼容，单系统同样可用。只需刷一次，之后升级固件不受影响。

共 64 个扇区，约需 1~3 分钟，期间请勿断电或拔线。

字库查看 / 校验

从 0xA0000 读取一个 16×16 字形，确认字库格式正确（白头佬共享字库亦可校验）。

3. 写入星历

    
流程：获取 TLE → 计算过境 → 连接串口 → 写入（会同步写入北京时间到 RTC）。机内操作：长按 0 进入多普勒模式，F+1~4 切换 4 个星历槽位。"删除全部星历"会清空 1-4 槽位数据，不可恢复。

    

      

        
        
      

      
      
    

    

  


  

    
4. 槽位名称编辑

    
读取指定槽位的卫星名称（多普勒主页面显示的"1:SO-50"中的名字），修改后写回，过境时间等数据不变。机内按 F+槽号 重新选中即可看到新名称。

    

      

        
        
      

      

        
        
      

    

    

      
      
    

  


  

    
5. 导出星历到电脑（调试诊断）

    
把当前计算出的过境星历（TLE、观测位置、过境窗口、每秒补偿频率表）导出为文件，便于核对计算、与其他软件对比、存档分析。无需连接对讲机，先在上方完成"计算最近过境"即可导出。JSON 含全部参数，CSV 可直接用 Excel 打开查看频率表。

    

      
      
    

  








  
信道管理


  

    
写入单个存储信道（MR）

    
通过 0x051D 写 EEPROM 命令把信道参数写入 SPI Flash。对讲机保持正常开机即可。注意：会覆盖指定信道现有数据，建议先导出校准/信道备份。


    

      

        
        
      

      

        
        
      

    


    

      

      

    

    
发射频率与“差频方向+差频”联动：填一边自动计算另一边；方向选“无”时即同频收发，差频不可填。写频时按固件格式存储（接收频率 + 频差值 + 方向）。


    

      

        
        
      

      

      

        
        
      

    


    

      

        
        
      

      

        
        
      

      

        
        
      

    


    

      

        
        
      

      

    


    

      

        
        
      

      

    


    

      
      
    

    

    

  


  

    
批量导入（CSV）

    
每行：信道号,名称,接收频率,发射频率,接收亚音,发射亚音,带宽,功率,调制,差频方向,差频。标题行可选。信道号与手台显示一致，为 1–1024。名称留空则清空。

    
    
    

      
    

    

  


  

    
导出信道（CSV）

    
读出机内信道并保存为 CSV，格式与批量导入一致，可直接编辑后再导入。名称自动解码中文（GB2312）；空信道自动跳过。范围较大时需要一两分钟，请保持开机连接。

    

      
      
      
    

    

  


  

    
清空信道（危险操作）

    
把范围内信道的频率、名称、属性全部恢复为出厂擦除态，固件将其视为未使用信道（切换信道/扫描自动跳过）。不可恢复！建议先导出 CSV 备份。大范围清空需要几分钟，完成后对讲机自动重启生效。
